# SIGAI — Sistema de Gestão de Arrendamento de Imóveis

**Disciplina:** Tecnologias de Base de Dados  
**Curso:** Licenciatura em Informática  
**Tema:** Gestão de Arrendamento de Imóveis  
**SGBD previsto:** MySQL  
**Tecnologias web previstas:** HTML, CSS e Python com Flask

### Descrição do problema

As agências imobiliárias precisam de gerir informações sobre os proprietários, os imóveis sob a sua responsabilidade, os inquilinos, os contratos de arrendamento e os pagamentos das rendas. Quando estes dados são controlados manualmente, podem surgir dificuldades na identificação dos imóveis disponíveis, no acompanhamento dos contratos e na verificação das rendas pagas e pendentes.

Para responder a este problema, propõe-se o desenvolvimento do SIGAI — Sistema de Gestão de Arrendamento de Imóveis, uma solução de base de dados destinada a apoiar as atividades de uma agência imobiliária.

O sistema permitirá registar os proprietários e os imóveis que estes disponibilizam para arrendamento, manter os dados dos inquilinos, formalizar os contratos de arrendamento e acompanhar as parcelas de renda e os respetivos pagamentos. Também permitirá consultar os imóveis disponíveis, identificar os contratos ativos e verificar as rendas pendentes ou vencidas.

A base de dados será implementada no MySQL, garantindo a organização e a integridade dos dados através de chaves primárias, chaves estrangeiras e restrições. Posteriormente, será utilizada num sistema web desenvolvido com HTML, CSS e Python com Flask, permitindo aos funcionários autorizados da agência registar, consultar, pesquisar e atualizar informações.

Desta forma, pretende-se melhorar a organização das atividades da agência, reduzir erros no tratamento dos dados e facilitar o controlo dos imóveis, contratos e pagamentos de renda.
